# Work queue glossary (D10=B)

Queues stay **separate**. Do not merge Help Desk, SSC Task List, and personal To-Do.

| Surface | What it is | Where | Complete how |
|---------|------------|-------|--------------|
| **Help Desk / SS tickets** | Service requests & escalations (SLA, autonomy band) | Ticket Portal `/activity` · hub inbox · **each SS function home → Outstanding tickets** · `/shared-services/tickets/{id}` | Open ticket → Resolve / draft approve |
| **SSC Task List / checklists** | Period operating cadence (monthly/quarterly…) | Function home Needs attention · `/shared-services/checklists` | Open task → status + evidence |
| **Personal To-Do** | Operator personal list | `/to-do` | Check off personal items |
| **HRIS process steps** | Joiner/leaver steps | HR → employee → run | Step done / waive (soft-stop override if partner hooks dry-run) |

## Per Shared Service section

Each SSC function home (Finance, HR, IT, Marketing, Legal) shows:

1. **Needs attention** — open checklist tasks (clickable → checklist task)
2. **Outstanding tickets** — open tickets for that service (clickable → ticket detail → Resolve)

## Conversion

No required ticket ↔ checklist conversion this quarter. Escalate checklist → ticket only when the escalate path already fires.
