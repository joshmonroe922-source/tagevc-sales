# Signent onboarding checklist — parse notes

Source: `TAGE Global - Onboarding Checklist - Signent.docx` (copied locally; gitignored).

## Flow in the portal

1. **Prospect** — talent acquisition checklist (recruiting through offer accepted)
2. **Advance to onboarding** — status → `onboarding`, starts Signent/TAGE onboarding template
3. **Active** — when onboarding checklist is marked complete

## Signent document sections (post–offer / hire)

| Section | Use in portal |
|---------|---------------|
| Pre-Employment / Conditional Offer | Onboarding template (post-accept confirmation + files) |
| Before Start Date | Onboarding template |
| Start Date | Onboarding template |
| Before First Payroll | Onboarding template |

Pre-hire recruiting steps (resume screen → offer accepted) are **not** fully covered as a recruiting pipeline in the Signent doc; those live in the separate **talent acquisition** template.

## Scope tagging on seeded items

| Scope | Meaning |
|-------|---------|
| `parent` | Applicable to Tage parent / shared HR generally |
| `signent` | Signent-oriented assignee, tooling, or process (RingCentral, Salesforce+RC, CEO-led device setup, quarterly bonus calc, Zoom review) |
| `both` | Same step for parent and Signent; assignee/tooling may still differ locally |

Mark Signent-specific rows as N/A when onboarding parent staff if they do not apply.
